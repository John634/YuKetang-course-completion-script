# 雨课堂自动刷课脚本

针对雨课堂主站（www.yuketang.cn）课程"学习内容"页的自动刷课工具，支持自动刷**视频**（静音、二倍速播放）、**讨论**（AI 生成发言并发布）和**作业**（AI 逐题作答并提交）三类内容。

## 功能

- 打开本机 Edge 浏览器，微信扫码登录（仅首次，登录态保存在本地）
- 图形化设置窗口：
  - 下拉框选择课程（自动读取"我的课程"列表，也可手动输入课程名）
  - 下拉框选择刷取内容类型：视频 / 讨论 / 作业
  - 可设置定时关闭（精确到分钟），到点自动停止
  - 刷作业时需填写 AI 接口（OpenAI 兼容：API 地址、密钥、**支持图片输入的视觉模型**名称）
  - 可勾选"作业提交前人工确认"：AI 选好答案后暂停，你在终端确认后再提交
- 自动跳过已完成条目，逐个处理未完成条目：
  - 视频：自动静音、二倍速播放、看完自动下一个
  - 讨论：随机复制一条其他同学的发言并发布（不使用 AI）
  - 作业：截图题目区域发给视觉 AI 作答（题目使用加密字体，文本提取是乱码，必须用支持图片输入的模型，如 qwen-vl-max / glm-4v / gpt-4o），提交并进入下一题，一套做完自动做下一套
- 三种停止方式：到达定时时间 / 全部刷完 / 终端按 `Ctrl+C`
- 防死循环：单条目最多尝试 3 次，刷不动的条目自动跳过并提示

## 使用说明

### exe 版（推荐，无需安装 Python）

1. 解压压缩包，双击运行 `yuketang_brush.exe`
2. 首次运行会在 Edge 中打开雨课堂，用微信扫码登录，登录后回终端按回车
3. 在弹出的设置窗口中选择课程、内容类型、（可选）定时关闭时间，点击"开始刷课"
4. 终端窗口会实时打印进度，随时可按 `Ctrl+C` 停止

要求：Windows 系统，已安装 Microsoft Edge 浏览器。

### Python 源码版

要求：Python 3.10+，已安装 Microsoft Edge。

```bash
pip install playwright
python yuketang_brush.py
```

可选参数：

```bash
python yuketang_brush.py --speed 2.0   # 视频倍速, 默认 2.0
python yuketang_brush.py --debug       # 只扫描并打印条目清单, 不实际刷
```

## 文件说明

- `yuketang_brush.py` / `yuketang_brush.exe`：主程序
- `yuketang_profile/`：首次运行后自动生成，保存登录会话，**请勿分享此目录**（内含你的登录态，等同账号密码）
- `yuketang_ai_config.json`：AI 接口配置，**内含 API 密钥，请勿分享**
- `yuketang_debug_*.html`：识别失败时自动生成的页面转储，用于排查适配问题

## 注意事项

- 视频以官方支持的 2 倍速播放，观看记录由平台心跳机制正常累积；建议分时段使用，避免短时间连续刷完全部内容
- 运行时请保持浏览器窗口可见（后台标签页可能被浏览器节流，影响进度记录）
- AI 生成的讨论发言和作业答案不保证质量/正确率，重要作业建议人工复核
- 讨论/作业页面结构未经过全面适配，识别失败时会自动保存 `yuketang_debug_discussion.html` / `yuketang_debug_homework.html`，提供给开发者即可快速适配
- 使用自动化脚本完成课程要求可能违反学校或课程的修读规定，由此产生的后果由使用者自行承担

## 常见问题

**弹窗里课程列表是空的？**
课程页结构可能不同。在下拉框中手动输入完整课程名即可继续；同时程序目录下会生成 `yuketang_debug_index.html`，可提供给开发者适配。

**提示"未识别到任何条目"？**
确认浏览器当前页是课程的【学习内容】页；程序目录下会生成 `yuketang_debug_frame*.html`，可提供给开发者适配。

**登录态失效？**
删除 `yuketang_profile` 目录后重新运行，重新扫码登录。
